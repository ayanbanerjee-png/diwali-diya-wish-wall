# Diwali Diya Wish Wall

Build a dark-themed single-page web app for Diwali called "DigiDiwali — A Virtual Place of Light".

Visual Aesthetics & Theme:

Deep dark slate or midnight blue background (#0B0D17) with warm gold/amber glowing accents.

Background visual: Animated ambient glowing Diyas (oil lamps) floating across the screen and subtle fireworks/sparkler particle effects.

A toggle in the top bar to switch between two atmospheric themes: "Lakshmi Puja (Night)" and "Choti Diwali (Evening)".

Header & Main Section:

Header title in elegant typography: "दीपावली" (Diwali).

Live Countdown Timer: Counting down to November 8, 2026 (Diwali Date). Show Days, Hours, Minutes, and Seconds.

Live Online Counter: Display a badge showing "100+ devotees lighting diyas online".

Interactive Features:

Light a Virtual Diya: A prominent button that allows users to click to "Light a Diya". Every click adds a glowing golden diya to a visual grid on screen and increments a global diya counter.

Virtual Wish / Blessing Wall: A form with inputs for "Your Name" and "Write a Wish/Greeting". Below it, display a live feed of glowing card posts containing user wishes.

Audio Player Bar (Fixed at Bottom):

Persistent audio bar playing ambient festive audio (or classic Lakshmi Aarti).

Include standard controls: Play/Pause, track title, and progress bar.

Web Audio API Effects: Add toggle buttons for "Temple Echo" and a "Reverb/Delay" slider to give the devotional audio an immersive temple feel.

Use Tailwind CSS, React, and Lucide icons. Keep the design minimal, serene, and clean.
